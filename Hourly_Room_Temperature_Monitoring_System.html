3. Counter Checking (per Area)

Counter checking is an independent check of the room temperature. The counter checker reads the temperature of the area using his/her own thermometer, and the system compares it with the latest hourly monitoring reading of the same area. A difference of more than is flagged as a discrepancy. Fill in the details, then type the counter check reading beside each room – the °C and the time are added automatically. Records are synced across devices.
